# DriveMint 🚗

### Smart Ride Management & Driver Earnings App

DriveMint is a Flutter-based mobile application built with Dart and Firebase. The project aims to provide drivers with a simple and user-friendly platform for managing ride activities and monitoring their earnings.

## 📱 About the Project

DriveMint is an ongoing mobile app development project focused on simplifying ride management through a clean user interface, cloud-based data storage, and Firebase authentication. It demonstrates practical skills in Flutter development, backend integration, and mobile UI design.

## ✨ Features

- **User Authentication:** User registration and login using Firebase Authentication.
- **Cloud Database:** Firebase Cloud Firestore integration for managing user information.
- **Driver Dashboard:** An interface for displaying driver-related information.
- **Ride Management:** Foundation for managing ride activities and ride records.
- **Earnings Management:** Planned support for tracking earnings and wallet balance.
- **User-Friendly Design:** Simple navigation and an intuitive mobile experience.

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- A Firebase project

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/vimaltamboli/DriveMint.git
   ```

2. Navigate to the project directory:

   ```bash
   cd DriveMint
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Configure your Firebase project and add the required platform configuration files.

5. Run the application:

   ```bash
   flutter run
   ```
